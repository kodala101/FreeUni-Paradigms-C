# FreeUni-Paradigms-C

This repository contains my completed assignments and coursework for the **Programming Paradigms** course at the **Free University of Tbilisi (FreeUni)**.

---

### 📌 Course Overview & Credits
The course explores low-level memory management, imperative, functional, and concurrent programming paradigms across multiple languages (C, C++, Scheme, Python, and Assembly). 

* **Course Instructor:** FreeUni Faculty of Computer Science & Mathematics
* **Starter Files & Materials:** All starter codebases, assignment specifications, handouts and test environments were originally provided by **FreeUni** (adapted from **Stanford University's CS107** programming paradigms curriculum).
* **Solutions:** The implementations, code solutions, and memory design logic within each assignment folder were written by me.

---

### 📂 Repository Structure

* `assn-01-kodala101/` — **Random Sentence Generator (C++)**: Pointer arithmetic, string parsing, and custom memory layout.
* `assn-02-kodala101/` — **Six Degrees of Kevin Bacon (C/C++)**: Generic memory handling, raw pointers, and graph search.
* `assn-03-kodala101/` — **Vector & Hashset Implementation (C)**: Implementing generic Data Structures in pure C using `void*` pointers and manual allocation.
* `assn-04-kodala101/` — **Assembly & Code Generation**: Low-level machine architecture, activation records, stack frames, and assembly execution.
* `assn-06-kodala101/` — **Multithreading & Concurrency**: Concurrent execution, thread synchronization, mutexes, and semaphores in C.
* `assn-07-kodala101/` — **Functional Programming (Scheme)**: Recursion, list processing, dynamic typing, and higher-order functions.
* `assn-08-kodala101/` — **Python & Networking / Web Scraping**: Dynamic typing, object-oriented concepts, RSS parsing, and network sockets.
